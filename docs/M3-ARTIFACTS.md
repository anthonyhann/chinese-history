## 二、三条铁律怎么落地的

**出处强制**：每条记录至少两个 `sources`——博物馆官方藏品记录页（`institutional`）+ 该馆开放数据许可页（`institutional`）。`_meta.source_snapshot` 记下 API 名、对象号、拉取日期。

**置信度分级**（`_meta.confidence`）：

| 级别 | 条数 | 含义 |
|---|---:|---|
| `high` | 441 | 名称是裸器物名或「形制 + 器物名」，可确定性对译，如 瓶 / 罐 / 三足鼎 |
| `medium` | 531 | 只对到器物类别，纹饰与题材留在 `name_en`，如 "Bowl with Peonies" → 碗 |
| `bare` | 2293 | 拿不到可靠中文对应，**保留博物馆原英文名**，`description` 留空等人工 |

**宁可留英文，不编中文名**。这是本轮最花时间的部分：第一版命名器把 "The Immortal Li Tieguai" 译成「鬲」（青铜器词表里的 `li` 吃掉了英文人名 Li），把 "Ewer with Dragon Handle" 译成「龙」，抽样发现后整体重写成分类型词表。

**`disputed[]`**：本轮没有发生馆方断代与史料断代冲突的条目，因此新增的 3308 条里 `disputed` 都是空。**故意不填**——空着是事实，硬塞一个「存疑」反而是编。

## 三、踩到的四个真坑（都是数据错误，不是格式错误）

1. **「Qin」正则吃掉「Qing」**：第一版朝代映射用 `Qin` 裸匹配，清朝藏品的 period 里含 "Qing"，400 余条被标成秦。改成 `Qin(?!g)` 并给所有朝代名加 `dynasty|period` 语境约束。
2. **地名吃掉朝代词**：「Jiangxi Province」里的 `Jiang` 命中 `Jin`（晋），261 条景德镇官窑全标成晋。改为「有年份就先按统治期对齐，名称只作校验」，名字与年份矛盾时**直接丢弃该条**（本轮共丢弃 61 条 conflict / ambiguous）。
3. **多朝代写法**：CMA 的 `culture` 常写成 "Yuan dynasty (1271–1368), Ming dynasty (1368–1644)"（制作年代 + 沿用/改制年代），取「第一个出现的朝代词」也不对。现在取与年份区间重叠最多的那个，并列时取文本靠前者。
4. **Met 从不写「金朝」**：Met 的 period 字段里 `Jin dynasty (266–420)` 是晋，金朝另有写法但也极少见；本批数据里 `Jin` 一律按晋处理，标成金的 15 条来自 CMA 明确写 `Jin dynasty (1115–1234)` 的条目。

## 四、已知的、还没解决的问题（写清楚，别让下游踩）

- **约 47% 的条目中文名是英文**（2293/3323）。对中文用户来说这是硬伤，需要人工或翻译流水线补齐。
- **`description` 全空**。本轮只做结构化事实（年代、材质、尺寸、收藏、图片），没有写一句描述——描述必须原创改写，机器批量生成会变成洗稿。
- **跨馆重复没有做实体合并**：`name_en` 相同的记录有 1519 条（320 个不同名称）。其中既可能有同一件文物被两馆都收录（罕见），更可能是同名不同件（「瓶」「碗」这类）。**不做自动合并**——合并错了比重复更糟。
- **断代区间来自馆方，与史料断代未必一致**。`date.original` 保留馆方原文，`date.start/end` 是馆方给的整数区间，`circa` 一律为 true。
- **Met 的 937 条里有 67 条没进库**：17 条是新石器时代/近代（超出朝代表），4 条名称与年份冲突，46 条年份跨多个朝代无法唯一归属。CMA 同类丢弃 104 条。宁可少，不可错。
